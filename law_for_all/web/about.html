서비스 구조 · AI 검증 방식

법이음은 “근거 없는 답변을 하지 않는 법률 AI”를 목표로 설계되었습니다.

답변 파이프라인

  1. ① 질문 이해

    생활 표현 토픽 라우팅 + 2-gram 조문 검색

  2. ② 원문 확보

    국가법령정보 Open API 실시간 원문(미설정 시 내장 데이터)

  3. ③ LLM 어댑터

    OpenAI · Claude · Ollama · 규칙엔진 중 선택

  4. ④ 환각 가드

    인용 화이트리스트 · 조문 언급 대조 · 실패 시 규칙엔진 대체

  5. ⑤ 근거 카드

    AI 문장과 분리된 법령 원문 · 원문 링크 · 기안문 인용

LLM 공급자 상태

환경변수 LLM_PROVIDER 하나로 기본값을 바꾸고, 화면 상단 메뉴에서 실시간 전환합니다.

    법령 데이터

    • · 연동 상태: 내장 데이터(국가법령정보센터 원문 2026-10-15 수집)
    • · 내장 법령: 법률 17종 + 하위법령 6종 · 조문 90개 (기준 2026-10-15)
    • · 생활 법률 상황 토픽: 17개 (검수된 쉬운 설명·행동 가이드·기관 연락처)
    • · 상황 분석 3관점(변호사·검사·판사) 지식베이스: 토픽별 주장·증거·전략, 위법성·제재, 법률 요건 사전
    • · 판례·해석례: Open API 연동 시 실시간 조회(시연 데이터에 사건번호를 지어내지 않음)

    환각 방지 장치

    1. LLM에는 검색된 근거 조문만 제공하고, 답변 문장마다 [[조문키]] 인용을 요구합니다.
    2. 근거 목록 밖의 인용 키는 서버에서 자동 제거하고, 인용이 하나도 없으면 답변을 폐기하고 규칙엔진으로 대체합니다.
    3. 본문의 “「법령」 제N조” 표현을 근거 원문과 대조하여 확인되지 않으면 ‘확인 필요’로 표시합니다.
    4. 근거 조문 카드에는 AI가 쓴 문장이 아니라 법령 원문만 표시하고 국가법령정보센터 원문 링크를 제공합니다.
    5. 기관 연락처·전화번호는 LLM이 만들지 않고 검수된 데이터만 사용합니다.
    6. 근거 조문이 검색되지 않으면 생성형 AI를 호출하지 않습니다.
